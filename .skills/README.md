# Skills locales

Añadir aquí únicamente skills específicos cuando exista un proceso repetible y validado.

| Skill | Cuando usarlo |
|---|---|
| `zammad-api/` | Autenticacion y endpoints generales de la API. |
| `zammad-tickets-pendientes/` | Listar y ordenar la cola de tickets no cerrados. |
| `zammad-responder-cerrar-ticket/` | Leer un ticket (`show`), preparar la respuesta, enseñarla y esperar aprobación, enviarla por correo (`email`) y, si se pide, cerrar. |
| `ninjaone-alertas-duplicadas/` | Limpiar alertas repetidas de NinjaOne para un mismo equipo. |
| `zammad-buscar-texto/` | Buscar una cadena en titulo y cuerpo de los tickets, con filtros y contexto. |
