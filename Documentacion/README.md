# Documentación auxiliar

Esta carpeta forma parte de la arquitectura del proyecto. Conserva material auxiliar y debe mantenerse enlazado desde la nota canónica que le dé contexto.

| Ruta | Uso |
|---|---|
| `Conexion/` | Scripts, accesos o recursos de conexión. |
| `Software/` | Material auxiliar de software y configuración saneada. |
| `Privado/` | Material sensible o local; queda excluido de Git. |

No incluir secretos, contraseñas, tokens ni claves privadas en contenido versionable.
